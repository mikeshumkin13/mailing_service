# 📬 Сервис управления рассылками

## Описание проекта

Веб-приложение на Django для создания, управления и отправки email-рассылок. Поддерживает регистрацию пользователей, разграничение прав доступа (пользователь / менеджер), управление клиентами и сообщениями, автоматическую отправку писем и хранение логов попыток.

Проект разработан в рамках курсовой работы Skypro.

---

## 🔧 Функциональность

- 🔐 Регистрация и авторизация пользователей
- 👤 Роли:
  - **Пользователь** — управляет только своими клиентами, сообщениями и рассылками.
  - **Менеджер** — имеет доступ ко всем данным.
- 📇 Клиенты:
  - CRUD-интерфейс
  - Привязка к пользователю
- 📨 Сообщения:
  - CRUD-интерфейс
  - Привязка к пользователю
- 📤 Рассылки:
  - CRUD-интерфейс
  - Указание периода, статуса, сообщения и клиентов
- 📊 Дашборд со статистикой:
  - Общее количество рассылок
  - Активные рассылки
  - Количество уникальных клиентов
- 🗂️ Логирование всех попыток отправки (успешных и неудачных)
- ⛔ Ограничение доступа: пользователь не может управлять чужими сущностями
- 🔁 Отправка рассылок через management-команду

## 📁 Структура проекта

mailing_service/
├── clients/ # Приложение управления клиентами
├── mailings/ # Приложение рассылок и логов
├── user_messages/ # Приложение для сообщений (текстов писем)
├── users/ # Кастомная модель пользователя, аутентификация
├── config/ # Настройки проекта
├── templates/ # Общие HTML-шаблоны
├── manage.py

## 🧪 Как запустить


# Установить зависимости
poetry install

# Применить миграции
python manage.py migrate

# Создать суперпользователя (необязательно)
python manage.py createsuperuser

# Запустить сервер
python manage.py runserver



## Как запустить рассылку вручную
python manage.py send_mailings
