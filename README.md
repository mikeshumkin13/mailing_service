##  О проекте

Сервис управления email-рассылками на Django.  
Реализованы CRUD-интерфейсы, отправка писем вручную и через командную строку, логирование попыток, главная страница с дашбордом.

### Возможности
- Управление клиентами, сообщениями и рассылками
- Отправка рассылок из админки и через `manage.py send_mailings`
- Лог каждой попытки отправки
- Главная страница со статистикой

 Реализовано с использованием Django 5.2 и Poetry.
